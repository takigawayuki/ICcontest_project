# 中国车牌数据集(CBLPRD-330k)分类统计报告

## 数据集概述

- **数据集名称**: CBLPRD-330k_v1
- **图片总数**: 684,220 张
- **车牌类别数**: 7 类

## 车牌类型详细说明

### 1. 普通蓝牌 🔵
**特征**：
- **底色**：蓝底白字
- **格式**：省份简称 + 字母 + 5位数字/字母组合
- **示例**：湘QSM5FJ、黑P113KJ
- **适用车辆**：小型汽车（轿车、SUV、小型客车等）
- **数量占比**：23.08%

### 2. 新能源小型车 🔋
**特征**：
- **底色**：渐变绿色（上绿下白）
- **格式**：省份简称 + 字母 + 5位数字（纯数字结尾）
- **示例**：辽QFU9887、粤EF89946
- **适用车辆**：小型新能源汽车（纯电动、插电混动）
- **位数**：8位（相比传统7位增加1位）
- **数量占比**：23.08%

### 3. 新能源大型车 🚌
**特征**：
- **底色**：黄绿双拼（上黄下绿）
- **格式**：省份简称 + 字母 + 4位数字 + D/F
- **示例**：藏E71415F、粤Z31632D
- **适用车辆**：大型新能源汽车（客车、货车等）
- **标识**：末位通常为D或F字母
- **数量占比**：15.38%

### 4. 单层黄牌 🟨
**特征**：
- **底色**：黄底黑字
- **格式**：省份简称 + 字母 + 5位数字/字母，可带"学"等后缀
- **示例**：云F5MTG学、晋ZFSD44
- **适用车辆**：
  - 大型汽车（货车、大客车）
  - 教练车（带"学"字）
  - 挂车（带"挂"字）
  - 摩托车
- **数量占比**：15.38%

### 5. 双层黄牌 🟨🟨
**特征**：
- **底色**：黄底黑字
- **排列**：上下两行排列
- **格式**：上行为省份简称+字母，下行为数字/字母组合
- **示例**：甘N66LK挂、蒙CSR73挂
- **适用车辆**：大型挂车、半挂车
- **特点**：通常带"挂"字标识
- **数量占比**：7.69%

### 6. 拖拉机绿牌 🟢
**特征**：
- **底色**：绿底白字
- **格式**：省份简称 + 2位数字 + 字母/数字组合
- **示例**：湘58NY032、宁85UTHLF
- **适用车辆**：拖拉机、农用运输车
- **特殊性**：编号规则与普通车牌不同
- **数量占比**：7.69%

### 7. 黑色车牌 ⚫
**特征**：
- **底色**：黑底白字/白框
- **格式**：多种格式（纯数字、省份+字母+数字+港/澳等）
- **示例**：晋PND9HJ、粤WX0FX澳、049746使
- **适用车辆**：
  - 外籍车辆
  - 领事馆车辆（带"使"字）
  - 港澳入境车辆（带"港"、"澳"字）
  - 外国驻华机构车辆
- **数量占比**：7.69%

## YOLO格式数据集转换说明

### 类别映射(classes.txt)

```
0: 普通蓝牌
1: 新能源小型车
2: 新能源大型车
3: 单层黄牌
4: 双层黄牌
5: 拖拉机绿牌
6: 黑色车牌
```

### 数据集划分建议

- **训练集**: train.txt 中的数据
- **验证集**: val.txt 中的数据
- **测试集**: data.txt 中的数据或从训练集中按比例划分

### YOLO格式转换步骤

1. 根据上述类别映射创建 `classes.txt` 文件
2. 为每张图片创建对应的 `.txt` 标注文件
3. 标注格式: `<class_id> <x_center> <y_center> <width> <height>`
4. 坐标值需要归一化到 [0, 1] 区间
5. 组织目录结构:
   ```
   dataset/
   ├── images/
   │   ├── train/
   │   ├── val/
   │   └── test/
   ├── labels/
   │   ├── train/
   │   ├── val/
   │   └── test/
   └── classes.txt
   ```
