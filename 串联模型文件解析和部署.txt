Step 1：模型转换（PC端）
RK3568 NPU 只跑 .rknn，需要先转换：
best.pt         →  ONNX  →  plate_detect.rknn
LPRNet_blue.pth  →  ONNX  →  lprnet_blue.rknn
LPRNet_green.pth →  ONNX  →  lprnet_green.rknn

工具链：rknn-toolkit2（在 x86 PC 上安装）
YOLO 转 ONNX：
yolo export model=best.pt format=onnx opset=12 simplify=True

LPRNet 转 ONNX（需要写导出脚本）：
torch.onnx.export(model, dummy_input, "lprnet_blue.onnx", opset_version=12)


ONNX 转 RKNN（需要量化数据集）：
rknn.load_onnx(model='plate_detect.onnx')
rknn.build(do_quantization=True, dataset='./calib_images.txt')
rknn.export_rknn('plate_detect.rknn')





Step 2：设备端推理串联逻辑（Python伪代码）
from rknnlite.api import RKNNLite

# 启动时加载三个模型
det_model = RKNNLite(); det_model.load_rknn('plate_detect.rknn'); det_model.init_runtime()
lpr_blue  = RKNNLite(); lpr_blue.load_rknn('lprnet_blue.rknn');   lpr_blue.init_runtime()
lpr_green = RKNNLite(); lpr_green.load_rknn('lprnet_green.rknn'); lpr_green.init_runtime()

for frame in camera_stream:
    # Stage 1: YOLO检测
    outputs = det_model.inference(inputs=[preprocess(frame)])
    boxes, scores, classes = postprocess_yolo(outputs)  # 需自己写NMS后处理

    for box, cls in zip(boxes, classes):
        # Stage 2: 裁剪
        plate_img = crop_and_resize(frame, box, size=(94, 24))  # LPRNet输入尺寸

        # Stage 3: 按类别路由
        if cls == 0:  # blue
            chars = lpr_blue.inference(inputs=[plate_img])
        else:         # green
            chars = lpr_green.inference(inputs=[plate_img])

        print(decode_chars(chars))




关键注意点
事项	说明
YOLO后处理	RKNN导出时建议把NMS留在CPU做，YOLO输出raw feature map需手写decode
LPRNet输入	固定 94×24 RGB，注意归一化方式要和训练时一致
NPU线程	RK3568有3个NPU核心，三个模型可分配不同core（core_mask参数）
量化精度	如果rknn int8精度掉严重，先用 do_quantization=False 测fp16
YOLO类别	确认best.pt训练时蓝/绿的class id是0/1，对应路由要匹配
